# Skala Internationalization

## Supported locales

- `es-CL` is the default locale.
- `en` is the alternate locale.

The selected locale is stored under `skala.locale` in `localStorage`. Locale is presentation state: graph structure, mastery, evidence and recommendation state remain unchanged.

## UI copy

Visible interface copy lives in flat, structurally equivalent dictionaries:

```text
/i18n/locales/es-CL.json
/i18n/locales/en.json
```

Components access copy through `useI18n()` and typed translation keys. Placeholders use `{name}` syntax. Runtime AI translation is intentionally excluded.

## Curriculum copy

The English seed catalogue remains the canonical structural catalogue. The explicit Spanish content layer lives in:

```text
/content/graph/translations.ts
```

`loadGraph(locale)` applies localized title and summary fields while preserving every node ID, edge, prerequisite, position input and content status.

## Adding a locale

1. Add the locale to `locales` in `/i18n/config.ts`.
2. Add a complete UI dictionary with the same keys as `en.json`.
3. Add explicit curriculum copy for every seed node.
4. Register the curriculum locale in `localizeNodes`.
5. Extend the parity tests in `/i18n/i18n.test.ts`.

This keeps components and application logic unchanged when locales such as `pt-BR` or `es-MX` are introduced.
